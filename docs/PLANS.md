# Plans

This is the canonical entrypoint for checked-in execution plans.

Use an execution plan when:
- The work spans multiple files or subsystems
- The task has notable ambiguity, sequencing, or rollout risk
- Decisions and open questions should stay versioned with the code

Locations:

- Active work:
  [exec-plans/active/README.md](/Users/dev/git/discode/docs/exec-plans/active/README.md)
- Completed work:
  [exec-plans/completed/README.md](/Users/dev/git/discode/docs/exec-plans/completed/README.md)
- Known debt:
  [exec-plans/tech-debt-tracker.md](/Users/dev/git/discode/docs/exec-plans/tech-debt-tracker.md)

Recommended execution plan fields:

- Goal / scope
- Background
- Milestones
- Current progress
- Key decisions
- Remaining issues / open questions
- Links to related documents

Update this file when the planning workflow or directory layout changes.
