# Product Sense

This document captures the durable product posture for Discode.

Core product expectations:

- Local-first: agent execution stays on the operator's machine.
- Relay-first: Discode should bridge control and output, not hide agent behavior behind a larger platform.
- Remote control should stay lightweight: Discord/Slack are conversational control surfaces, not full dashboards.
- Sessions should remain durable across disconnects and operator context switches.
- Multi-project workflows should stay manageable through one daemon and predictable channel/session mapping.
