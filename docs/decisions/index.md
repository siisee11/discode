# Decision Records Index

Canonical for: architecture decision record (ADR) location, naming, and lifecycle status
Audience: contributors and agents making cross-cutting or long-lived technical decisions
Update when: ADR policy changes, ADR statuses change, or new records are added

## Location and Naming

- ADRs live in `docs/decisions/`.
- File names use zero-padded numeric prefixes plus a short slug: `0001-example-decision.md`.
- Keep one durable decision per ADR.

## Template

- Use [`adr-template.md`](adr-template.md) for new decision records.
