# Active Execution Plans

Canonical for: work that is currently in progress and needs durable checkpoints
Audience: contributors actively implementing multi-step changes
Update when: a plan starts, progresses, pauses, or is completed

Current active plans:

- None currently. Add a new plan here when the next multi-step implementation begins.

When adding a new active plan:

- create one focused markdown file in this directory
- include goal, scope, background, milestones, progress, decisions, open questions, and related links
- move the file to `../completed/` when the work ships or is intentionally abandoned with notes
